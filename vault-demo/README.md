# Vault demo

Este es un vault de [Obsidian](https://obsidian.md) minimo, pensado como memoria "visible" del stack.

## Estructura

- `00-Inbox/` - notas rapidas, sin clasificar todavia.
- `Agents/` - notas sobre el comportamiento, decisiones y aprendizajes de los agentes del stack.

## Como abrirlo

1. Abre Obsidian -> "Open folder as vault" -> selecciona esta carpeta (`vault-demo/`).
2. Explora el grafo (Ctrl/Cmd + G) para ver como se conectan las notas.

Este vault se mantiene vacio de contenido "real" en el repo base - los agentes lo van poblando.
