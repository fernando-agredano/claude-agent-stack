# Resumen Dashboard

El dashboard del proyecto está construido con **React + Vite + D3**.

- React para la UI de componentes
- Vite como bundler y dev server
- D3 para visualizaciones de eventos de agentes en tiempo real

Los eventos se capturan via hooks SubagentStart/SubagentStop y se persisten en SQLite.
