# Resumen Memory Engram

El sistema de memoria persistente usa **memory-engram** como capa de almacenamiento a largo plazo.

- Permite guardar memorias con tags e importancia numérica
- Se consulta al inicio de cada conversación relevante
- Expone un MCP server que otros agentes pueden invocar directamente
